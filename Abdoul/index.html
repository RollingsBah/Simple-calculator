How It works ?

Display Selection

  • display.value: represents whatever appears on the calculator screen.

Displaying Values

  • appendValue(): This function is called whenever a calculator button is pressed.

Tokenizing the Expression

  • tokenizeExpression(): It converts a text expression into understandable pieces called tokens.

Reading Every Character

  • for (let i = 0; i < expression.length; i++): The loop examines the expression one character at a time.

Reading Numbers

  • if (/\s/.test(char)) { continue;}: Detects numbers. It also supports decimals.

Multiplication Symbol

  • else if (char === "x"): The calculator displays X but JavaScript uses *

Reading Operators

  • "+-*/()".includes(char): Recognizes +, -, *, /, (, ) and stores them.

Invalid Characters

  • throw new Error("Invalid expression");: Stops the program if the user enters something unexpected.

Evaluating the Expression

  • evaluateExpression(expression);: This is the calculator's brain.

Tokenization First

  • const tokens = tokenizeExpression(expression);: This is the calculator's brain, 12+5*3 becomes [12, "+", 5, "*", 3]

Current Position

  • let index = 0;: Keeps track of where we are in the token list.

Peek Function

  • function peek() { return tokens[index]; }: Looks at the current token without moving.

Advance Function

  • function advance() { return tokens[index++]; }: Returns the current token and moves to the next one.

Addition and Substraction

  • parseExpression(): Handles + and -

Multiplication and Division

  • parseFactor(): Handles * and /

Recognizes brackets

  • parseFactor(): Handles the smallest units. it recognizes numbers, negative numbers, positive numbers, parentheses

Parentheses

  • ( ): It enters the parentheses, solves the expression inside, checks for the closing ).

Final Check

  • if (peek() !== undefined): Ensures every token has been processed.

Algorithm

  1. START
  2. Get the mathematical expression from the display.
  3. Convert the expression into tokens:
    • Ignore spaces.
    • Read complete numbers (including decimals).
    • Convert 'x' to '*'.
    • Store operators and parentheses.
    • If an invalid character is found, stop with an error.
  4. Evaluate the tokens using recursive descent parsing:
    1. Parse factors:
      • Number
      • Unary + or -
      • Parenthesized expression
    2. Parse terms:
      • Perform multiplication and division.
      • If dividing by zero, report an error.
    3. Parse expressions:
      • Perform addition and subtraction.
  5. Verify that all tokens were consumed.
    • If extra tokens remain, report an invalid expression.
  6. Return the computed result.
  7. END

Conception

The calculator is designed in three logical layers, each with a single responsibility:

  1. User Interface: Displays the expression and collects button presses (appendValue() updates the display).
  2. Lexical Analysis (Tokenization Layer): Converts the raw string (for example, "12+5x3") into structured tokens ([12, "+", 5, "*", 3]). This makes the expression easier to process.
  3. Parsing and Evaluation (Computation Layer): Uses a recursive descent parser with three levels of precedence:
    • parseFactor() handles numbers, unary signs, and parentheses.
    • parseTerm() handles multiplication and division.
    • parseExpression() handles addition and subtraction.

This layered design respects the order of operations (BODMAS/PEMDAS), avoids the security risks of eval(), makes the code easier to maintain, and allows future extensions such as adding exponentiation (^), modulus (%), or mathematical functions (sqrt, sin, cos) without redesigning the entire calculator.
