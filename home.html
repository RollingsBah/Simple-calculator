MODULUS AND EXPONENT

Understanding the Algorithms Behind Modulus (%) and Exponent (^)

Modulus Algorithms (%)

The modulus operator returns the reminder after dividing one number by another. It is commomly used to determine whether a number is even or odd and for cyclic operations.

  1. Start
  2. Input the first number (A).
  3. Input the second number (B).
  4. Divide A by B
  5. Return the reminder using A % B.
  6. Display the reminder.
  7. Stop.
A % B = reminder

Exponent Algorithms (^)

The exponent opeartor raises a number (base) to the power of another number (exponent) by multiplying the base repeatedly.

  1. Start
  2. Input the base number.
  3. Input the exponent
  4. Multiply the base by itself repeatedly according to the exponent
  5. Display the final result
  6. Stop
