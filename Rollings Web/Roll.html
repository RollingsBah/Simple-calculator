About This Project

During my internship, I was assigned the task of improving an existing scientific calculator application.

The calculator already supported several mathematical operations such as addition, subtraction, multiplication, division, exponentiation, square root, decimal-to-fraction conversion and modulus.

My responsibility was to extend the calculator by implementing two additional mathematical features:

Combination (nCr)

Calculates the number of ways of selecting r objects from n objects without considering order.

Quadratic Equation Solver

Solves quadratic equations entered in the format ax² + bx + c eq y using the quadratic formula.

Combination (nCr)

Combination is a mathematical operation used to determine the number of possible selections of r objects from a group of n objects where the order of selection does not matter.

Formula

nCr = n! / (r! (n-r)!)

Algorithm

  1. Start the program.
  2. Receive the values of n and r.
  3. Validate that n and r are positive integers.
  4. Calculate n factorial.
  5. Calculate r factorial.
  6. Calculate (n-r) factorial.
  7. Apply the combination formula.
  8. Display the result.
  9. Stop.

Algorithm Flow

Start
↓
Input n and r
↓
Validate Values
↓
Calculate Factorials
↓
Calculate nCr
↓
Display Answer
↓
End

Example

Calculate:

5C2

n = 5
r = 2

5C2 = 5! / (2! x 3!)

5C2 = 120 / (2 x 6)

Answer = 10

Quadratic Equation Solver

The quadratic equation solver is used to solve equations in the form:

ax² + bx + c eq y

The calculator converts the equation into standard quadratic form:

ax² + bx + (c-y) = 0

Formula

x₁ = (-b + √D) / 2a

x₂ = (-b - √D) / 2a

Where:
D = b² - 4ac

Algorithm

  1. Read the equation entered by the user.
  2. Search for the "eq" symbol.
  3. Separate the equation and the y value.
  4. Extract coefficients a, b and c.
  5. Convert the equation into standard form.
  6. Calculate the discriminant.
  7. If D is less than zero, display "No Real Roots".
  8. Otherwise calculate the roots.
  9. Display x₁ and x₂.

Algorithm Flow

Start
↓
Read Equation
↓
Extract a,b,c
↓
Calculate D
↓
D < 0 ?
↓
Calculate Roots
↓
Display Result

Example

2x²-4x+5eq1

Convert:

2x²-4x+4=0

a = 2
b = -4
c = 4

D = (-4)² - 4(2)(4)

D = -16

Result: No Real Roots

Challenges Encountered

1. Parsing Quadratic Equations

Reading an equation entered in the format ax²+bx+ceqy and extracting the values of a, b and c was one of the main challenges.

2. Input Validation

The calculator needed to handle invalid inputs and prevent incorrect calculations.

3. Mathematical Implementation

The algorithms were implemented manually without relying on external mathematical libraries.

Solutions Implemented

  • A custom equation parser was created to identify coefficients from the user input.
  • Validation checks were added to detect invalid numbers and expressions.
  • Mathematical algorithms such as factorial, combination calculation and custom square root calculation were implemented manually.
